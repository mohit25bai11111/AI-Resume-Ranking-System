# Project Overview: AI Resume Parser & Ranking System

## Objective
To develop an automated, data-driven candidate evaluation platform that streamlines recruitment by parsing unstructured resume files, extracting key technical qualifications, comparing them against job descriptions, and displaying ranked results on a modern dashboard.

## Key Goals
1. Reduce initial screening time for recruiters from hours to seconds.
2. Provide standard, unbiased scoring based on direct skill overlap and semantic context.
3. Deliver an intuitive dashboard interface for reviewing applicant metrics.
